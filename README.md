# OGZ «Sakartvelo» — сайт оперативной группы захвата

Вымышленный ролевой проект. Одностраничный сайт с тёмной тактической темой,
переливающимися градиентами, тремя языками (RU / EN / KA), модальными досье
подразделений и офлайн-режимом (PWA). Без сборки и зависимостей — чистые
HTML, CSS и JS.

## Что внутри

```
ogz-site/
├─ index.html            разметка страницы, метатеги, переключатель языков
├─ styles.css            тема, сетки, анимации, адаптив, reduced-motion
├─ i18n.js               словари RU / EN / KA (202 ключа)
├─ script.js             язык, модалки, форма, меню, PWA, анимации
├─ fonts.css             локальные @font-face
├─ fonts/                Inter, Oswald, Noto Sans Georgian (WOFF2)
├─ icon.svg              иконка сайта и PWA
├─ og-card.jpg           превью 1200×630 для соцсетей
├─ manifest.webmanifest  манифест PWA
├─ sw.js                 офлайн-кеш (версия ogz-v3)
└─ .nojekyll             отключает Jekyll на GitHub Pages
```

## Локальный запуск

Открыть `index.html` двойным кликом можно, но корректнее через локальный сервер
(иначе не зарегистрируется service worker):

```bash
cd ogz-site
python -m http.server 8123
# открыть http://127.0.0.1:8123/
```

## Публикация на GitHub Pages (без git)

1. Зайти на github.com под своим аккаунтом.
2. **New repository** → имя, например `ogz-site` → **Public** → **Create**.
   (Pages для приватного репозитория требуют платного плана.)
3. На странице репозитория: **Add file → Upload files**.
4. Перетащить **содержимое папки** `ogz-site` (не саму папку), чтобы
   `index.html` лежал в корне репозитория. Нажать **Commit changes**.
5. **Settings → Pages** → Source: **Deploy from a branch** →
   Branch: `main`, папка `/ (root)` → **Save**.
6. Через 1–2 минуты сайт откроется по адресу
   `https://<логин>.github.io/ogz-site/`.

Тему оформления GitHub (тёмная/светлая) можно переключить в
**Settings → Appearance** — на сам сайт это не влияет, у сайта своя тёмная тема.

## Бесплатный домен

Проверенные варианты (на момент подготовки):

| Домен | Статус | Где регистрировать |
|---|---|---|
| `ogz.eu.org` | свободен | nic.eu.org (бесплатно, нужна привязка NS) |
| `ogz.neocities.org` | свободен | neocities.org |
| `ogz.rf.gd`, `ogz.42web.io`, `ogz.ct.ws` | свободны | infinityfree.com |
| `ogz.vercel.app`, `ogz.netlify.app`, `ogz.pages.dev`, `ogz.github.io` | заняты | — |

Если имя `ogz` занято на бесплатном хостинге, подойдёт
`ogz-site.netlify.app`, `ogz-site.pages.dev` или `ogz-site.vercel.app`.

Регистрация домена требует вашего аккаунта и подтверждения e-mail — это
нельзя сделать за вас. Для связки с GitHub Pages нужен файл `CNAME` с доменом
в корне репозитория и DNS-записи у регистратора.

## Настройки

- Язык по умолчанию — русский, выбор хранится в `localStorage` (`ogz-lang`).
- Все тексты — в `i18n.js`: ключ `data-i18n="..."` в HTML, значение в словаре.
- После правок статики поднимите версию кеша в `sw.js` (`ogz-v3` → `ogz-v4`),
  иначе у вернувшихся посетителей останется старая копия.
- Форма ничего не отправляет: это демонстрация с валидацией и уведомлением.
